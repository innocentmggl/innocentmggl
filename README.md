### Featured project

**[CodeSentinel](https://github.com/innocentmggl/codesentinel)** is an AI code reviewer for Java teams. Give it a pull
request URL and it posts inline review comments and one-click *Apply suggestion* fixes on GitHub.

- Hexagonal architecture on **Spring Boot 4 and Java 25**, with the dependency rules enforced by ArchUnit tests
- Model-agnostic: local **Ollama** or cloud **Gemini / OpenAI**, switched by a Spring profile
- **RAG over the codebase** with pgvector, and background review jobs so GitHub webhooks never time out
- Validates model output against the diff before posting, so comments always land on real lines
